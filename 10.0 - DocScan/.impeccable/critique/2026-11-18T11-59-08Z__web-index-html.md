## Overall Impression

A trustworthy, quiet workspace whose layout is right (pages, photo, text side by side) but whose text pane is crowded: the letter, the hero by PRODUCT.md, gets the least room. The single biggest opportunity: give the document its space back and make one next step obvious at each stage.

## What's Working

- Photo and text side by side with resizable, foldable panes: the core review task is one glance.
- Flags flow: highlight in text, list below, word panel with the photo crop. Principle 2 is visible.
- Contrast and dark mode are clean everywhere; save state is always on screen.

## Priority Issues

**[P1] The document gets too little room**
- Why: at 1440x900 the text pane shows about six lines; three tool rows (read, edit, a wrapped "استخدام النسخة") and an open flags list take the rest. On a phone the letter starts 490 px down an 800 px screen.
- Fix: versions move into a history popover so tools fit one row; the flags list opens shorter with one-line items; on phones the app bar hides inside a draft and tools collapse into one row.
- Command: impeccable layout, impeccable adapt

**[P1] An empty draft shows every tool as if a page existed**
- Why: "اقرأ الصفحة" (primary), photo tools, editing tools and export are all live with no photo; the read status even shows the previous draft's reader.
- Fix: until photos exist, the photo pane becomes the drop target and the other tools are off; read status resets per draft.
- Command: impeccable onboard, impeccable harden

**[P2] Three solid green buttons at once**
- Why: "إضافة صور", "اقرأ الصفحة" and "إنتاج الملف" all shout; principle 4 asks for one obvious next step.
- Fix: the primary follows the stage: add photos, then read, then produce.
- Command: impeccable distill

**[P2] The flags list repeats one long sentence nine times**
- Why: "قراءة غير مؤكدة (درجة الثقة 22%)، قارن مع الصورة الأصلية" under every item is noise; the word panel cuts the same line off.
- Fix: short form ("غير مؤكدة، 22%") in the list and panel; human and AI notes stay in full.
- Command: impeccable clarify

**[P2] Phones: small targets and covered thumbnails**
- Why: 40 px buttons, 30 px tools; page tools sit over the page thumbnail on touch screens.
- Fix: 44 px on touch; page tools in a row under the thumbnail.
- Command: impeccable adapt

**[P2] Settings dialog**
- Why: one long form whose Save button scrolls away; key fields run right to left (the "sk-ant-" hint shows reversed); the template file picker says "Choose File / No file chosen" in English.
- Fix: fixed footer, left-to-right key fields, an Arabic file button.
- Command: impeccable polish

## Persona Red Flags

**Senior records clerk (project persona)**: opens a new draft and sees a green "اقرأ الصفحة" that does nothing; reads "المحرك: PaddleOCR" with no idea what it means; the letter area feels small next to all the buttons.

**Alex (power user)**: no bullet or numbered lists, no strike, cannot format several lines at once; versions need two controls.

**Sam (keyboard / screen reader)**: good roles and labels throughout; block tools appear only on focus (fine), but the photo pane has no text alternative beyond the page label.

**Casey (phone)**: icon-only lightning, save and options buttons; four tool rows before the letter; 30 px tools.

## Minor Observations

- Home repeats "المسودات" in the page title and the list title.
- Two stacked bars in a draft (app bar and draft bar).
- The image editor toolbar wraps, leaving Save and Cancel alone on a second row.
- The format menu shows only "Word (.docx)" when the server cannot convert; then it should not be a menu.
